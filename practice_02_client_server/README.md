# Практическая работа №2
**Базовые CRUD-операции через консоль**

Севостьянов Роман Андреевич, группа 3ИСП11-43.

Консольное меню для просмотра, добавления, изменения статуса и удаления задач. SQL-запросы используют параметры с ?, после изменения выполняется commit().

## Что в папке
- `отчет.pdf` - отчёт по работе
- `src/` - исходный код и база данных `app.db`
- `screenshots/` - изображения результатов и предпросмотра интерфейса

## Запуск на Windows
Из корня репозитория запустить `START_02.bat`.

# Практическая работа №1
**Инициализация базы данных SQLite**

Севостьянов Роман Андреевич, группа 3ИСП11-43.

Создание базы SQLite и таблицы tasks с полями id, title и status. Таблица создаётся только при отсутствии, поэтому повторный запуск не приводит к ошибке.

## Что в папке
- `отчет.pdf` - отчёт по работе
- `src/` - исходный код и база данных `app.db`
- `screenshots/` - изображения результатов и предпросмотра интерфейса

## Запуск на Windows
Из корня репозитория запустить `START_01.bat`.

# Практическая работа №4
**Интеграция Flask и SQLite: чтение данных**

Севостьянов Роман Андреевич, группа 3ИСП11-43.

Страница получает записи из таблицы tasks через SELECT. Функция get_connection() задаёт sqlite3.Row, после чего Jinja2 выводит поля задачи и её статус. Выполненные задачи зачёркиваются.

## Что в папке
- `отчет.pdf` - отчёт по работе
- `src/` - исходный код и база данных `app.db`
- `screenshots/` - изображения результатов и предпросмотра интерфейса

## Запуск на Windows
Из корня репозитория запустить `START_04.bat`.
После запуска открыть http://127.0.0.1:8081/
Сервер останавливается Ctrl+C.

Примечание: изображения страниц в папке screenshots получены при локальном рендере HTML-шаблонов с демонстрационными данными.

**Выполнил:** Севостьянов Роман Андреевич  
**Группа:** 3ИСП11-43  
**Работы:** 1-7, Python / SQLite / Flask  

Во всех `practice_XX_client_server` размещены:
- `отчет.pdf` - отчёт с описанием, результатами и контрольными вопросами;
- `src/` - программа и база данных;
- `screenshots/` - изображения результатов и интерфейсов.

## Запуск на Windows

1. Скачайте репозиторий через **Code -> Download ZIP**, распакуйте.
2. Запустите `SETUP_FIRST.bat` (устанавливает Flask в `.venv`).
3. Запустите `START_01.bat` ... `START_07.bat` для выбранной работы.
4. Для №3-7 откройте http://127.0.0.1:8081, оставив терминал включённым. Остановка сервера - `Ctrl+C`.

Программа №1 создаёт таблицу tasks; №2 позволяет управлять задачами в консоли; №3-7 постепенно развивают веб-приложение. Каждая работа хранит свою копию базы.

Ссылка на исходные методички: https://github.com/softboxdev/programming_course/tree/main/practice
